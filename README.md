# CodeAlpha_Basic-Chatbot
This is a simple rule-based chatbot built using Python as part of the CodeAlpha Python Programming Internship.

## Project Description
The chatbot interacts with the user through the terminal.  
It responds to a few predefined inputs such as greetings and basic questions.

## Features
- Simple rule-based responses
- Console-based interaction
- Continuous conversation until user exits

## Technologies Used
- Python 3
